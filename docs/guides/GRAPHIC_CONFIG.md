# Importer Pro 图形化配置指南

## 1. 概述

图形化配置位于导入向导的 **Step 3（模板配置）**。完整向导共 4 步，界面布局以蓝图 [ui/layout.md](../.arcmesh/ui/layout.md) 为准：

| 步骤 | 名称 | 说明 |
| :--- | :--- | :--- |
| Step 1 | 来源选择 | 选择数据文件或笔记应用（Excel/CSV/JSON/Enex/Notion/Apple Notes） |
| Step 2 | 文件管理 | 选择文件或从历史记录快速导入（显示新增条数） |
| Step 3 | 模板配置 | 本指南主题：数据处理、列映射、校验、派生字段、匹配规则、分流、输出 |
| Step 4 | 进度执行 | 批量导入、进度展示与取消 |

以下各小节对应 Step 3 的配置内容，按向导推进顺序排列，全程无需编写代码。

## 2. Step 3：模板配置

### 2.1 数据概览

进入配置后首先显示已解析文件的数据概览（前 3 行），帮助用户了解数据结构。

```text

┌───────────────────────────────────────────────────┐
│ 姓名 │ 身份证号 │ 部门 │ 职位 │
│ 张三 │ 110101199003071234│ 技术部 │ 工程师 │
│ 李四 │ 110101198505152345│ 产品部 │ 产品经理 │
│ 王五 │ 110101199111112356│ 技术部 │ 技术总监 │
└───────────────────────────────────────────────────┘


```

### 2.2 列映射

将源列映射到目标字段。

| 配置项 | 说明 |
| :--- | :--- |
| **源列名** | Excel/CSV 的实际列名（下拉选择） |
| **目标字段名** | 模板中使用的变量名（自动填充或手动修改） |
| **字段类型** | 文本/数字/日期/身份证/邮箱/手机号 |
| **处理规则** | 额外处理（如日期格式、数字精度） |

**映射方式**：
- **自动匹配**：插件自动尝试匹配列名
- **手动映射**：用户通过下拉菜单手动选择

### 2.3 数据校验

设置数据校验规则。

| 校验项 | 说明 |
| :--- | :--- |
| **必填** | 该字段不能为空 |
| **唯一** | 该字段值不能重复 |
| **校验规则** | 身份证/邮箱/手机号/日期/长度/数值范围 |
| **默认值** | 字段为空时填充 |

### 2.4 派生字段

从预设规则列表中选取。

| 规则名称 | 来源字段 | 输出字段 |
| :--- | :--- | :--- |
| 提取性别 | 身份证号 | 性别 |
| 提取生日 | 身份证号 | 生日 |
| 生成哈希 | 任意字段 | _hash |
| 智能链接 | _hash | _link |
| 拆分字段 | 标签 | 标签数组 |
| 合并字段 | 姓、名 | 全名 |

### 2.5 匹配规则

设置文件名自动匹配规则。

| 匹配方式 | 说明 | 示例 |
| :--- | :--- | :--- |
| **正则表达式** | 最灵活 | `^员工.*\.xlsx$` |
| **通配符** | 简单易用 | `员工档案_*.xlsx` |
| **精确匹配** | 完全一致 | `员工信息.xlsx` |

### 2.6 数据分流

根据条件将数据放入不同文件夹。

```text

┌─────────────────────────────────────────────────────────────┐
│ 分流条件 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ 条件: validateID 身份证号 == true │ │
│ │ 目标文件夹: 人员档案 │ │
│ │ ─────────────────────────────────────────── │ │
│ │ 条件: validateID 身份证号 == false │ │
│ │ 目标文件夹: 待核验档案 │ │
│ └──────────────────────────────────────────────────────┘ │
│ │
│ [+ 添加分流条件] │
└─────────────────────────────────────────────────────────────┘


```

### 2.7 输出设置

控制笔记生成位置和方式。

| 配置项 | 说明 |
| :--- | :--- |
| **目标文件夹** | 笔记存放路径（支持变量） |
| **笔记名称** | 文件名模板（支持变量） |
| **冲突策略** | 覆盖/追加/跳过/重命名 |
| **增量更新** | 仅当内容变更时更新 |

> **目标文件夹留空时**：回退到设置中的"默认输出目录"（`paths.outputFolder`），再未设置则写入 Vault 根。所有目录均为 Vault 内相对路径，可在设置页修改（见用户指南 §4.4）。

### 2.8 笔记预览

实时预览生成效果，支持切换到代码模式。

```text

┌─────────────────────────────────────────────────────────────┐
│ 预览 #1: 张三 │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ --- │ │
│ │ 姓名: 张三 │ │
│ │ 性别: 男 │ │
│ │ 生日: 1990年03月07日 │ │
│ │ --- │ │
│ │ # 张三 的档案 │ │
│ │ [[人员档案/e10adc3949]] │ │
│ └──────────────────────────────────────────────────────┘ │
│ │
│ [📝 切换到代码模式] │
└─────────────────────────────────────────────────────────────┘


```

## 3. 操作按钮

| 按钮 | 行为 |
| :--- | :--- |
| **💾 保存模板** | 仅生成模板文件（保存到设置中的模板目录 `paths.templates`），不执行导入 |
| **🚀 保存模板并导入** | 生成模板文件 + 立即执行导入 |
| **📝 切换到代码模式** | 切换到 Handlebars 代码编辑模式 |
| **🎨 切换到图形模式** | 切换回图形化配置界面 |

## 4. 配置示例

### 员工档案导入配置

列映射：
姓名 → 姓名 (文本)
身份证号 → 身份证号 (身份证)
部门 → 部门 (文本)
职位 → 职位 (文本)

数据校验：
身份证号: 必填 ✅, 校验: 身份证格式
姓名: 必填 ✅

派生字段：
提取性别 (来源: 身份证号)
提取生日 (来源: 身份证号)
生成哈希 (来源: 身份证号, 长度: 10)

匹配规则：
正则表达式: `^员工.*\.xlsx$`

数据分流：
validateID 身份证号 == true → 人员档案
validateID 身份证号 == false → 待核验档案

输出设置：
目标文件夹: {{_folder}}
笔记名称: {{_hash}}
冲突策略: 跳过
