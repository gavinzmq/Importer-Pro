# Importer Pro 快速开始

## 1. 安装

### 从 Obsidian 社区安装

1. 打开 Obsidian 设置 → 第三方插件
2. 关闭安全模式
3. 点击浏览，搜索 "Importer Pro"
4. 点击安装并启用

### 手动安装

1. 从 GitHub Releases 下载最新版本
2. 解压到 `.obsidian/plugins/importer-pro/`
3. 在 Obsidian 中启用插件

## 2. 首次导入

### 第 1 步：准备数据

创建或准备一个 Excel 文件，格式如下：

| 姓名 | 身份证号 | 部门 | 职位 |
| :--- | :--- | :--- | :--- |
| 张三 | 110101199003071234 | 技术部 | 工程师 |
| 李四 | 110101198505152345 | 产品部 | 产品经理 |

### 第 2 步：打开导入对话框

点击左侧边栏的 **📥 导入** 图标。

### 第 3 步：选择来源

在向导 **Step 1** 选择 **Excel 文件**，**Step 2** 选中你的 Excel 文件（或从历史记录快速导入）。

### 第 4 步：配置模板

如果是首次导入，插件会在 **Step 3** 打开图形化配置：

1. **列映射**：将"姓名" → "姓名"，"身份证号" → "身份证号"
2. **数据校验**：勾选身份证号和姓名为必填
3. **派生字段**：添加"提取性别"和"提取生日"
4. **匹配规则**：填写 `^员工.*\.xlsx$`
5. **数据分流**：身份证合法 → 人员档案，不合法 → 待核验档案
6. **输出设置**：目标文件夹 `{{_folder}}`，笔记名称 `{{_hash}}`

### 第 5 步：保存并导入

点击 **"保存模板并导入"**，等待导入完成。

## 3. 查看导入结果

导入完成后：

- 身份证合法的笔记 → `人员档案/` 文件夹
- 身份证不合法的笔记 → `待核验档案/` 文件夹

## 4. 后续使用

以后导入同类型的文件，只需：

1. 选择文件
2. 插件自动匹配模板
3. 直接点击导入

无需重复配置！

## 5. 常见问题

**Q: 导入失败？**

A: 检查文件格式是否正确，身份证号是否为 18 位。

**Q: 如何修改模板配置？**

A: 在设置页 → Importer Pro → 模板列表 → 点击"编辑"。
