## 1. 布局基础

|属性|值|
|---|---|
|**Modal 宽度**|`720px`（桌面） / `96%`（平板） / `100%`（移动）|
|**最大高度**|`90vh`（内容溢出滚动）|
|**间距 Token**|`--space-xs(4px)` / `--space-sm(8px)` / `--space-md(16px)` / `--space-lg(24px)` / `--space-xl(32px)`|
|**Body 内边距**|`24px 28px`（桌面） / `16px 20px`（移动）|
|**字体层级**|标题 `h4`(16px) / 正文 `14px` / 辅助 `13px` / 小字 `12px`|

**布局规格**：

|元素|类型|宽度|
|---|---|---|
|标题行|`📋 选择数据表单` + 描述|100%|

│  │  • 姓名 → 去除首尾空格 (trim)                 [✕]      │ │

│  └────────────────────────────────────────────────────────────┘ │

```

**子模块规格**：

|子模块|行数|说明|
|---|---|---|
|**列格式化**|最少 2 行（操作行 + 已配置列表）|包含下拉选择器、参数输入、添加按钮|
|**行清洗**|固定 2 行（复选框行 + 自定义规则行）|复选框横向排列，间距 16px|
|**列处理**|最少 2 行（操作行 + 已配置列表）|同列格式化|

**下拉选项（列格式化）**：

```
转换为身份证类型 | 格式化为日期 | 格式化为数字 | 格式化为字符串 | 去除空格 | 替换文本 | 提取子串
```

**下拉选项（列处理）**：

```
拆分 | 合并 | 映射 | 提取正则 | 填充默认值
```

**交互行为**：

- 每次添加规则，立即在下方“已配置”列表中新增一行。
    
- 点击 `[✕]` 删除规则，预览区同步刷新。
    
- 所有规则在预览区应用，让用户即时看到效果。

### 5.6 区块 5：列映射表（按需映射）

**描述**：**只映射需要导入的列**，未映射的列在数据处理时被忽略。支持手动添加映射行和自动匹配。

**ASCII 界面图**：

```
┌──────────────────────────────────────────────────────────────────┐
│  📋 列映射 (只映射需要的列，未映射的列将被忽略)              │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │  源列名        →  目标字段        →  类型      →  操作   │ │
│  │  ──────────────────────────────────────────────────────── │ │
│  │  姓名             姓名              文本        [▼]      │ │
│  │  身份证号         身份证号          身份证      [▼]      │ │
│  │  部门             部门              文本        [▼]      │ │
│  │  职位             职位              文本        [▼]      │ │
│  │  ──────────────────────────────────────────────────────── │ │
│  │  [➕ 添加映射行]  [🧹 自动映射]  [🗑 清空所有]          │ │
│  │  ──────────────────────────────────────────────────────── │ │
│  │  💡 可用源列: 姓名 / 身份证号 / 部门 / 职位 / 薪资 / 入职日期 / 标签 │
│  │     (仅显示未映射的列)                                   │ │
│  └────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

**表格行规格**：

|列|宽度|组件|说明|
|---|---|---|---|
|源列名|`22%`|`<select>` 下拉|选项仅为**未映射的列**|
|目标字段|`28%`|`<input type="text">`|模板中使用的字段名|
|类型|`25%`|`<select>` 下拉|文本 / 身份证 / 数字 / 日期 / 忽略|
|操作|`15%`|`[✕]` 按钮|删除该映射行（保留至少 1 行）|

**按钮行为**：

- `[➕ 添加映射行]`：新增空行，源列下拉自动填充下一个未映射列。
    
- `[🧹 自动映射]`：将源列名与目标字段名**完全相同**的列自动添加（如 `姓名 → 姓名`）。
    
- `[🗑 清空所有]`：二次确认后清空全部映射，仅留空提示。

### 5.7 区块 6：派生字段

**描述**：基于已有字段通过函数计算生成新字段。支持预设规则一键套用。

**ASCII 界面图**：

│  │  生日        │  从身份证提取生日         │  身份证号  │  [✕] │ │
│  │  _hash       │  MD5 取前 10 位           │  身份证号  │  [✕] │ │
│  │  _link       │  智能链接                 │  姓名      │  [✕] │ │
│  │  ──────────────────────────────────────────────────────── │ │
│  │  [+ 添加派生字段]  [📋 预设规则]                        │ │

**表格行规格**：

|列|宽度|组件|
|---|---|---|
|字段名|`18%`|`<input type="text">`|
|规则|`42%`|`<input type="text">` + 预设按钮|

|操作|`12%`|`[✕]` 按钮|

**预设规则弹窗**（点击 `📋 预设规则` 触发 `SuggestModal`）：

```

### 9.3 行为与约束

- 路径使用 `normalizePath` 校验，仅允许 Vault 内相对路径（越界 → `SECURITY_001`）。
- 保存即写回 `data.json`（按 `schemaVersion` 迁移）。变更触发：模板目录 → `TemplateScanner.refresh()`；Helper/Hook 目录 → 增量重载（失败回滚）；日志目录 → 重建文件句柄；缓存目录 → 迁移后重建索引。
- 📂 路径设置中的缓存/日志默认位于 `.obsidian/importer-pro/`（Obsidian 标准数据区），仍可修改、非强制固定。
- 🔧 高级：`重置为默认设置` 写回 `DEFAULT_SETTINGS`；`导出/导入配置` 为 JSON，导入前校验 `schemaVersion`，非法则拒绝（`API_001`）。
