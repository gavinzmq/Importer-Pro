### 选择文件交互（平台差异）

**描述**：`[📁 选择文件]` 按钮经 **`IFilePicker` 接口 + `FilePickerFactory` 反射工厂**（见 architecture.md §5）调用平台原生文件选择能力，UI 组件不感知平台差异。

| 平台 | 触发行为 | 文件来源 |
| :--- | :--- | :--- |
| **桌面端** | 弹出 **OS 原生文件选择对话框**（`DesktopFilePicker`） | 本地磁盘，按来源格式过滤 |
| **移动端** | 弹出 **系统文档选择器**（`MobileFilePicker`） | 文件 App / iCloud / 第三方文件提供方 |

**交互行为**：

- **格式过滤**：`accept` 按 Step 1 所选数据源映射（Excel→.xlsx/.xls、CSV/TSV→.csv/.tsv、JSON→.json、HTML→.html、Enex→.enex、Notion→.zip、Apple Notes→.notes）。
- **选择成功**：返回 `FileInfo`，文件列表追加**会话条目**并**自动选中**；列表已存在同一文件（去重键：Vault 内 = 相对路径；外部 = 绝对路径/移动端文件标识，**含历史条目**）→ **仅选中、不新增**。选择成功后**不自动跳转**，由用户确认后点击"下一步"。
- **会话条目生命周期**：**未导入自动删除**——向导关闭（未成功导入）即移除会话条目、不写入历史；**导入成功保留**——转为历史条目（模板名+条数+时间戳），随 `importHistory` 裁剪保留最近 20 条。
- **下一步门控**：存在选中条目 → `[下一步]` 可用，点击进入 Step 3；无选中条目 → 禁用（历史条目"直接导入"不受影响）。
- **路径引用**：选中文件仅记录路径/读取句柄（桌面 = 本地绝对路径 / Vault 相对路径；移动端 = 文件提供方标识/URI），**不预加载进内存、不写临时磁盘缓存**；Vault 内文件 Step 3 解析/预览按需从原路径读取，**外部文件经选择时持有的 File/Blob 句柄按需读取**（`FileInfo.blob`，D81，桌面/移动端一致）。权威设计见 architecture.md §2.8。
- **可访问性约束**：解析/预览期间原文件需保持可访问；文件被移动/删除或移动端 URI/句柄失效 → `IO_002` 提示重选。
- **取消**：返回 `null`，向导状态不变、停留 Step 2。
- **读取失败**：错误码 `IO_002 文件读取失败`，按钮下方内联提示并允许重选。
- **平台判定**：唯一入口为工厂内部 `Platform.isDesktop` / `Platform.isMobile`，禁止组件内散落平台分支。
- **里程碑注记（2026-09-03，D66–D68）**：D65"选择成功仅回显、不自动进入 Step 3"升级为"合并列表追加会话条目 + 自动选中 + 手动下一步进入 Step 3"；会话条目**未导入自动删除、导入成功转历史保留**；所选文件**仅记录路径引用**（不预加载、不写临时缓存），外部文件端到端导入当时随 roadmap 后续文件导入流程（R01 类）排期。
- **外部文件端到端导入（2026-09-03，D81）**：D65/D66/D75"外部文件不落库、仅排队"边界**已解除**——Step 2 选中的 Vault 外文件携带 File/Blob 句柄，可进入 Step 3 解析/预览并完成 Step 4 写入 Vault 笔记（原文件不复制进 Vault）。外部文件**不跨会话保留句柄**：其导入历史条目仅展示记录与「🗑 删除」（原文件不可用，重新导入请重新选择），Vault 内文件历史保持「🔄 直接导入 / 📝 修改模板 / 🗑 删除」。

**规格**：按钮高度 `36px`、内边距 `0 16px`；会话条目内文件名超长省略（`text-overflow: ellipsis`），大小标签置于文件名右侧。

    - **过滤空行（含第一行）**：所有数据列值 **trim 后**均为空的行过滤（含第一行与前导空行；修复不 trim 导致全空格/首行空行漏判）。执行于行筛选**之前**。
    - **过滤重复表头**（D124）：**在所有过滤和筛选之后**执行——删除与**将成为表头的行（清洗+筛选后剩余第一行）逐值相同**的后续行（数据中重复打印的表头）。这样即使表头前的说明行/占位行被行筛选排除，重复表头仍能基于**真实将成为表头的行**正确判定（而非 D123 的「清洗后首行」——它可能随后被行筛选剔除）。API/默认解析路径（importFile，表头已被消费为列名）按「值 == 列名」过滤（无首行基准、表头已定，保持原状）。
    - **执行顺序**（向导表格类，D124）：rawRows 解析 → **过滤空行**（removeEmptyRows）→ **行筛选**（占位列名）→ **过滤重复表头**（removeDuplicateHeaderRows，基准 = 清洗+筛选后剩余第一行）→ **表头提升** → 列映射/派生/note-output → 校验回填。
    - **执行载体**：跨行操作单行 Handlebars 无法表达，为**引擎开关**（core/row-clean.ts `removeEmptyRows`/`removeDuplicateHeaderRows`/`promoteHeaderRow`）——向导路径（预览/导入）统一由 `applyWizardTransform { promoteHeader }` 按 D124 顺序执行；配置随模板 frontmatter `row.clean`（remove_empty/remove_duplicate_header）保存，不产编译段。
    - **旧配置迁移**：`row.clean` 数组 `removeEmpty` → remove_empty（`dedupe`/`filterInvalid` 忽略）；`row.remove` `duplicateHeader` → remove_duplicate_header（`byIndex` 忽略、`byContent` → 行筛选规则）；旧 row-filter 段预置「任意列 非空」规则 → remove_empty；`header_row`/`merge_rows` 废弃忽略；旧 `row-remove` 段保存时自动清理。
    - **刷新级别**：开关变更 / 筛选增删 → 表头（列名）变化时自动补充映射并 L2 重建列映射区块（D91），否则 L1 预览；预览「筛选后 X / Y 行」X = 空行+筛选+重复表头后行数 − 1（表头行不产笔记，`countRowsAfterHeader`，D124 顺序）。

- **行筛选**（D96，Excel 式包含式筛选）：
    - 控件行：列下拉（表格类 = 占位列名 `列1..N` + **任意列**；非表格类 = 解析列名 + **任意列**）+ 条件下拉（13 种）+ 值输入（`为空`/`非空` 时隐藏值输入）+ [➕ 添加]；
    - **任意列**（D97）：列下拉选「任意列」时对整行所有列值匹配（任一列命中即通过），承接 `byContent` 删除迁移；
    - **语义**：保留「全部规则均匹配」的行（多条规则 **AND** 组合，同 Excel 多列筛选）；
    - **执行顺序**（D124）：**过滤空行之后、过滤重复表头之前**执行——被过滤空行移除的行不参与筛选；行筛选剔除的行不再参与后续重复表头判定与表头提升；全部由 `renderPreprocess` 渲染 Handlebars 执行（D98，编译为 `{{#unless (条件)}}{{set "_skip" true}}{{/unless}}`，非 JS 函数调用）；
    - **统计行**：实时显示「筛选后 X / Y 行」，X 为过滤空行 + 行筛选 + 重复表头后数据行数（表格类扣除表头行，D124 顺序）；
    - 大小写敏感口径同 D93；数字比较（大于/小于等）先数值化再比较（非数值按字符串比较）；`为空`/`非空` 判定空串/空白/缺列；
    - 已配置列表标签示例：`任意列 不包含 测试` / `薪资 大于 10000`。

- **校验规则**（D118，已实现）：
    - 控件行：字段下拉（全部数据列）+ 类型下拉 + 消息输入（可空，默认按类型生成）+ 可选参数输入（`length`/`range` 显示 `最小值,最大值`）+ [➕ 添加]；
    - **类型下拉（8 种，Validator 内置）**：必填 `required` / 身份证 `id-card` / 邮箱 `email` / 手机号 `phone` / 日期 `date` / 长度 `length`(min,max) / 数值范围 `range`(min,max) / 唯一 `unique`（批次级唯一，添加时文案注明）；
    - **存取**：随 [💾 保存到模板] 写 frontmatter `validation`（不产编译段——校验契约 = frontmatter，template-schema §2）；进入 Step 3 回填；
    - **预览联动**：校验结果回填 `_valid/_errors/_warnings/_status`，预览区行首显示 ✅/⚠️/❌ 标记（§5.7）；`_status` 可用于输出命名表达式（`{{_status}}`）；
    - **跳过语义**：校验**不自动 `_skip`**（是否跳过由模板决定，D115；原「过滤无效数据」开关已废弃，D122）；
    - 已配置列表标签示例：`身份证号 身份证格式` / `姓名 必填`。
