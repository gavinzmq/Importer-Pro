# 决策记录：Step 3 区块 5 顺序编排 + 特殊字段行 + 保存到内容模板（D130–D134，已实现）

## 背景（用户需求，2026-09-06）

1. **区块 5 列映射行顺序可调**：列映射表应可调整行顺序——行顺序即**内容模板顺序**（内容模板 = 模板第二阶段把预处理数据渲染为 Markdown 正文的 `content` 段，glossary「内容模板」；字段在正文中的呈现顺序由映射行顺序决定）。
2. **「已添加设置」顺序可调**：行下设置面板中已添加设置应可调整顺序——设置顺序即**管道顺序**（该行值管线执行顺序：≥2 步 `pipe` 的阶段顺序、1 步直调的函数顺序）。
3. **特殊字段显示与配置**：列表里应显示并可配置 `_skip`、`_folder` 等**特殊字段**（`_` 前缀保留字段）；目标字段对这些字段应有**下拉选择**；特殊字段应**唯一**（每个至多一行）。
4. **与上面区块联动**：特殊字段行应与上方区块（区块 3 模板元信息 / 区块 4 行配置）联动。
5. **添加设置补齐特殊字段设置 + 默认设置**：「添加设置」里应补齐应对这些特殊字段的设置（专属设置项）；新建特殊字段时，设置里应自动添加该特殊字段的**默认设置**。
6. **区块 3 新增按钮**：区块 3 应添加「保存到内容模板」按钮。

约束衔接：D98 唯一逻辑载体（编译段执行、渲染顺序即代码顺序）；D99–D101 pipe（≥2 阶段顺序）；D117 行下设置面板与分组下拉；D120/D125/D127「输出到」noteType；D129 output 段与 `_folder`/`_fileName`（本决策的特殊字段行与其同源）；template-schema §3 保留字段契约。

## 决策内容

### D130 区块 5 行顺序调整（内容模板顺序）

- **入口**：区块 5 列映射表每行「操作」列新增顺序操作 `↑` / `↓`（上移/下移一格，首行 `↑`、末行 `↓` 禁用）；实现时可选加拖拽把手（`⋮⋮`，drag & drop），二者语义一致——**行顺序 = 编译后 preprocess 段内 `set` 行顺序 = 内容模板（正文）中字段呈现顺序**（D98 渲染顺序即代码顺序）。
- **语义**：行顺序只影响**同一段内**的 `set` 顺序——纯映射行在 `column-mapping` 段、派生行在 `derived` 段（D108 编译按 rule 拆分）；跨段顺序仍由段清单顺序决定（row-filter → column-mapping → derived → output → note-output，template-schema §9）。预览/Step 4 随编译产物同步刷新。
- **持久化**：行顺序随 preprocess 段内代码顺序自然持久化，不新增配置字段；反编译按 `set` 行序回填行序。
- **刷新级别**：行重排 → L2 区块内（列表局部重建，保持 `scrollTop`，D91）+ L1 预览。
- **与「输出到」的关系**：重排不改字段归属（noteType 随行走）；主笔记与附加笔记 object 内字段顺序 = 行顺序过滤后的顺序（实现时确认：`_notes` object 参数序列是否按行序）。

### D131 设置顺序调整（管道顺序）

- **入口**：行下「已添加设置 (N)」面板每项增 `↑` / `↓`（或拖拽把手）——**设置顺序 = 该行值管线执行顺序**：1 步 = 直调函数顺序（先应用者靠前）；≥2 步 = `(pipe 源 (stage A …) (stage B …) …)` 阶段顺序（先执行者靠前）。
- **类型隐含转换定位**：`数字/日期/布尔` 类型的隐含转换（toNumber/toDate/toBoolean）为**预置首步**（D117 与首步同语义设置去重）——**不参与重排**、恒置于管线首位；其余设置（列格式化/列处理/计算/链接/条件校验/提取/特殊字段设置）可自由重排。
- **派生行**：列派生为派生产出（rule），其后续设置链（D117 派生后叠加）顺序同本规则；派生项本身固定在首位（不可下移）。
- **编译口径**：重排即改变 pipe 阶段/直调步骤在编译产物中的顺序；**语义敏感设置**（条件校验 = 整链替换式末步、条件警告/smartLink = set 后附言，D119/D126）重排受限——条件校验恒为值管线**末步**、warn/link 附言恒在 set 行之后（其相对位置不随设置链重排，仅管道步骤可重排）；实现时确认受限集合。
- **反编译**：按 pipe 阶段顺序/直调顺序回填设置面板顺序；旧模板无顺序元数据（代码顺序即顺序）→ 按代码顺序回填。
- **刷新级别**：设置重排 → L2 面板 + L1 预览。

### D132 特殊字段显示与配置（目标字段下拉 + 唯一）

- **特殊字段候选清单**（template-schema §3 保留字段的**可配置子集**）：`_skip`（跳过记录）/ `_folder`（目标文件夹）/ `_fileName`（文件名）/ `_status`（状态，模板可写）/ `_warnings`（警告列表）/ `_link`（智能链接）。
  - **排除**：`_index`（引擎注入、只读）、`_hash`（引擎/派生生成，不作目标字段）、`_notes`（note-output 段管理，配置入口在「📑 笔记类型」面板 D120）、已移除的 `_valid`/`_errors`（D125）。
- **显示**：区块 5 列表**显示**当前配置中的特殊字段行（读模板/回填时按 `set "_xxx"` 识别为特殊字段行；无配置时经目标字段下拉新建）；特殊字段行与普通映射行同表混排，目标字段处显示「特殊」小标签（`_` 前缀可辨识）。
- **目标字段下拉**：目标字段控件由纯 `<input>` 改为 **输入 + 下拉**组合——下拉含「特殊字段」分组（列出上述候选），选 `_xxx` 即把该行目标字段设为特殊字段；普通文本输入行为不变（D125 来源→目标自动清洗仍生效，仅对普通行）。
- **唯一性**：每个特殊字段**至多一行**——列表中已存在该特殊字段时，下拉禁用该项（灰置 + 提示「已配置」）；保存/反编译时遇重复特殊字段行按行序保留首行、其余忽略并 Notice 提示。
- **行形态**：特殊字段行**来源可留空**（值由默认设置/设置链产出）；「类型」列禁用/固定（`_skip`=布尔、`_folder`/`_fileName`/`_status`/`_link`=文本、`_warnings`=列表）；「输出到」列禁用（特殊字段为预处理保留字段，由引擎消费，不进入笔记渲染数据——`_skip` 由 DataPipeline、`_folder`/`_fileName` 由 NoteGenerator/pipeline、`_link` 由 NoteGenerator 消费）。
- **编译**：特殊字段行与普通行同样产 `{{set "_xxx" …}}`（其值管线 = 默认设置 + 可叠设置）；持久化在对应段内（按 D133 联动口径，`_folder`/`_fileName` 与 output 段同源、`_skip` 与 row-filter 段同源）。
- **刷新级别**：特殊字段增删/编辑 → L2 区块内 + L1 预览；目标字段下拉展开不触发刷新。

### D133 特殊字段与上方区块联动 + 添加设置补齐特殊字段设置与默认设置

**联动（双向同步，区块 3/区块 4 为权威配置入口，特殊字段行为其区块 5 视图）**：

- **`_folder` / `_fileName` ↔ 区块 3 输出位置及命名规则（D129）**：二者共享同一表达式——区块 3 两个输入框为**权威编辑入口**；区块 5 特殊字段行显示当前表达式并可展开「输出表达式」内联编辑（与区块 3 值同步）。区块 3 编辑 → 特殊字段行同步显示；特殊字段行编辑 → 区块 3 输入框回填；保存时统一编译进 `output` 段（D129，不重复产段）。区块 3 输出位置/命名**未配置**时，特殊字段行以空态提示（「在区块 3 配置或在此输入表达式」）。
- **`_skip` ↔ 区块 4 行筛选（D96/D98）**：行筛选规则集即 `_skip` 的写入条件（`{{#unless (全部规则 AND)}}{{set "_skip" true}}{{/unless}}`）——区块 4 为**权威编辑入口**；区块 5 `_skip` 特殊字段行显示当前规则集（标签摘要）并可展开「条件」内联编辑（复用行筛选条件编辑器）；双向同步，任一入口增删规则即时反映到另一处与预览。
- `_status` / `_warnings` / `_link` 不与区块 3/4 联动（`_link` 与设置页「启用智能链接」开关语义相关但不做 UI 联动，实现时确认）。

**添加设置补齐特殊字段设置（D133）**：

- 「添加设置」分组下拉对**特殊字段行**增补**「特殊字段」组**（或按字段动态显示专属项，实现时确认）——普通行的 7 组（列格式化/列处理/列派生/计算/链接/条件校验/提取，D117/D119/D126/D128）照常可用（可叠加），特殊字段行另可选用其专属设置项：
  - `_skip` → **条件**（行筛选条件编辑器，规则集与区块 4 共享）；
  - `_folder` / `_fileName` → **输出表达式**（Handlebars 表达式编辑，与区块 3 同步，D129 口径）；
  - `_status` → **固定值**（字符串常量编辑，模板可写字段 D125）；
  - `_warnings` → **条件警告**（条件 + 警告文本，D119 附言口径，编译 `{{#if 条件}}{{set "_warnings" (push _warnings "文本")}}{{/if}}`）；
  - `_link` → **smartLink**（目标文件夹 / 回退文件夹，D119 链接组口径，编译 `{{set "_link" (smartLink _hash "目标" "回退")}}`）。
- 专属设置同样入该行设置链（行下设置面板），参与 D131 顺序编排与编译。

**新建特殊字段的默认设置（D133，新建即自动加入设置面板）**：

| 特殊字段 | 默认设置（新建时自动加入） | 说明 |
| :--- | :--- | :--- |
| `_skip` | **条件**：行筛选条件编辑器（规则集与区块 4 共享） | 默认无规则（空态引导「添加条件」），有规则即产 row-filter 段条件块 |
| `_folder` | **输出表达式**：文件夹 Handlebars 表达式编辑（与区块 3 同步） | 缺省 `paths.outputFolder`（空 = Vault 根）；值管线支持叠加其它设置 |
| `_fileName` | **输出表达式**：文件名 Handlebars 表达式编辑（与区块 3 同步） | 缺省 `{{_hash}}` |
| `_status` | **固定值**：字符串常量编辑 | 供命名表达式 `{{_status}}` 引用 |
| `_warnings` | **条件警告**：条件 + 警告文本（push `_warnings`） | 可叠多条，各产一条 `#if` 附言 |
| `_link` | **smartLink**：目标文件夹 / 回退文件夹 | `(smartLink _hash "目标" "回退")` |

默认设置可在设置面板内 `✎` 编辑参数、`✕` 删除（删除后该特殊字段行回落为空 `set`，引擎按缺省语义消费）；`✕` 删除特殊字段行 = 移除该特殊字段配置（回落引擎默认行为：`_skip` 不产条件块、`_folder`/`_fileName` 回落 output 段/D112 默认目录/`_hash` 等），并在对应上方区块同步清除/复位。

### D134 区块 3「保存到内容模板」按钮

- **入口**：区块 3 模板操作按钮行增第四枚 **`[💾 保存到内容模板]`**（位于 [💾 保存到模板] 之后）。
- **语义**：把区块 5 列映射的**行顺序与字段集**写回所选模板的**正文 content 段（内容模板）**——按行序生成/更新正文字段布局（如按序输出 `**字段名**：{{字段}}` 行），使导入生成的笔记正文中字段呈现顺序与映射行顺序一致。
- **与 [💾 保存到模板] 独立**：保存到模板 = 编译 preprocess 标记段 + frontmatter（D95/D98，不动正文）；保存到内容模板 = 只写正文 content 段（不动 preprocess/frontmatter）；两按钮可分别执行，也可依次执行。
- **范围口径**：正文仅含**进入笔记渲染数据的普通映射字段**（输出到 主笔记/附加笔记/所有笔记 的字段，按其行序；「不输出」D127 与特殊字段行不进入正文——`_skip`/`_folder`/`_fileName` 等保留字段由引擎消费）；多笔记类型（D120）各笔记的正文字段按其「输出到」归属的字段子集按行序生成（实现时确认是否按附加笔记类型拆分正文生成）。
- **手写正文处理**：content 段存在手写内容时，按「字段行识别」（`{{字段}}` 引用）重排已识别字段行、保留无法识别的自定义内容位置（实现时确认识别规则与重排算法）；全新/骨架模板（D92）按行序生成标准字段列表。空映射（区块 5 无行）时禁用并提示。
- **门控**：未选模板时禁用（同 [💾 保存到模板]，D92/D95）；写入失败 `TEMPLATE_005` 内联提示。
- **刷新级别**：保存成功 → L1 无刷新（仅 Notice，同 D95）；保存后再次进入 Step 3 时正文顺序按 content 段反编译/识别回填区块 5 行序（实现时确认回填入口）。

### 实现口径（2026-09-06，开放项逐条定案）

1. **操作形态**：行顺序与设置顺序均提供 `↑/↓` 按钮 **+ `⋮⋮` 拖拽把手**（用户确认二者并存）。行 ↑/↓/拖拽**仅同段内有效**（纯映射 / 派生 / 真实特殊行各自成段；跨段由段清单固定，操作拒绝并提示）——`wizard-data.moveMappingRow` 纯函数 + UI 禁用/拒绝；设置 ↑/↓/拖拽仅限**可重排值链项**（`isReorderableSetting`：附言 warn/link、条件校验、条件计算、固定值不可重排；派生项固定首位；`类型`隐含转换不在 settings 数组、天然恒首步）——`moveRowSetting` 纯函数。
2. **特殊字段模型**：`SPECIAL_FIELDS = [_skip,_folder,_fileName,_status,_warnings,_link]`（保留字段可配置子集，`_index/_hash/_notes` 排除）；`_skip`/`_folder`/`_fileName` 为**区块 4/3 联动视图行**（数据源 = `transform.filters` / `transform.output`，**不入 cfg.mappings**，UI 底部特殊字段区显示、✕ 清除对应上方区块配置并复位，区块 3/4 为权威编辑入口、双向同步——0↔非0 边界变化时自动刷新区块 5）；`_status`/`_warnings`/`_link` 为**真实行**（入 cfg.mappings，source 可空、type=text、noteType 禁用）。
3. **专属/默认设置**：`_status`=固定值（新增 `MappingSetting { group:'special', op:'fixed' }`，编译 `{{set "_status" "值"}}`，decode 还原；值源为字符串字面量、可叠值型步骤）；`_warnings`=条件警告（复用 `compute.warn`，比较基准 = 行来源列；无来源列时 UI 提示、编译不产）；`_link`=smartLink（复用 `link.smartLink`）。新建真实特殊行经目标字段下拉自动注入 `defaultSpecialSetting`；普通行「添加设置」七组照常可用。
4. **消歧**：独立特殊真实行编译前置 `{{!-- ipro:specialrow:<target> --}}` 标记行，反编译据此无歧义还原（与普通映射行无标记的 warn/link 附言区分，D119 兼容不回归）；`_folder/_fileName` 若出现在 column-mapping 段则忽略（output 段权威）。
