# 决策记录：Step 2 会话文件队列与文件驻留管理（D66–D68）（2026-09-03）

## 背景

D65（`2026-09-03-file-picker-implementation.md`）落地后，Step 2 选择文件的现状为：原生文件选择器可用，但选完文件回到 Step 2 后仅于按钮右侧**回显文件名**，既不进入列表也不推进，无法点击"下一步"进入 Step 3，形成死端体验。

用户实测反馈期望行为：

1. 选好文件后，Step 2 的列表应**新增该文件条目并自动选中**；若列表中已存在该文件信息，则**直接选中、不新增**。
2. 之后可点击"下一步"进入 Step 3。
3. 选中文件应**加载到内存**；内存不足时转**临时磁盘缓存**；意外退出或导入成功时应**删除缓存/内存**。

本决策在不破坏 D62–D64 平台抽象与 D65"外部文件不落库"边界的前提下，补齐 Step 2 会话状态与文件驻留生命周期。

## 决策内容

| # | 决策 | 理由 |
| :--- | :--- | :--- |
| D66 | Step 2 新增"**待导入文件**"会话队列区块（与"历史记录"区块并列）：`pickFile` 成功 → 追加 `ImportFileEntry` 条目并**自动选中**（单选高亮）；**去重键** = 文件来源标识（Vault 内文件 = Vault 相对路径；外部文件 = 绝对路径；移动端 = 文件提供方标识），队列已存在同一文件 → **仅选中、不新增**；条目支持移除（`✕`），移除后若为选中项则清空选中 | 队列是本次会话的导入候选集；去重避免同文件重复条目；与历史记录"快速导入"语义解耦 |
| D67 | "**下一步**"门控 = 存在选中条目：有选中 → 可点进入 Step 3；无选中 → 禁用（历史记录"直接导入"不受影响）。保持"选择成功**不自动跳转**"（停留 Step 2 由用户确认）与"取消返回 `null` 不改向导状态"。D65"仅回显"升级为"队列条目 + 自动选中" | 由用户自主确认后推进；状态机可预测；外部文件"不落库"边界不变（见 D68） |
| D68 | **文件驻留**：新增 `FileLoadManager` 管理选中文件的驻留介质——默认加载到内存（`ArrayBuffer`）；内存预算超阈值（桌面 128MB / 移动 64MB，与 STANDARDS §6 内存 <200MB 对齐）转**临时磁盘缓存**（`paths.cacheDir/tmp/`，命名 `会话ID + 内容哈希` 防重名）。**清理生命周期**：Step 4 成功完成 / 向导关闭（含取消与意外退出）→ 释放内存并删除临时文件；插件 `onunload` 兜底清理；下次启动清扫 `tmp/` 孤儿文件（仅限本插件目录）。缓存写入失败 → 降级纯内存并记 `IO_001`（WARN）；清理失败仅 WARN 不阻塞。Step 3 解析/预览经 `FileLoadManager` 读取驻留介质（内存或临时路径） | 内存优先保证解析/预览即时性；磁盘缓存兜底大文件；临时目录属插件内部数据区（`.obsidian/importer-pro/`），不写入 Vault 笔记区，故不违反 D65"不落库"；成功/异常双路径清理防残留 |
| 边界 | 外部文件的**端到端导入**（Step 4 完成写入）仍随后续路线图（roadmap R01 类）提供；本决策仅放开"Step 2 队列 + Step 3 解析/预览读取" | 与 D65 里程碑边界一致，不扩大本次范围 |
