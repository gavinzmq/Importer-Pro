# 决策：UI 渲染策略

## 背景

Step 3 控件多、关联强（列映射→派生→预览依赖链）。初期控件变更触发的整页 `contentEl` 重建带来明显"刷新感/跳顶/焦点丢失"。

## 决策

- **分级刷新**：L1 仅刷新预览 / L2 刷新区块内 / L3 数据源级刷新（沿依赖链 映射→派生→预览）。
- `.ipw-body` 为持久滚动容器，Step 内 DOM 身份**不变**；刷新前记录并恢复 `scrollTop`，抑制跳顶与焦点丢失。
- 禁止 Step 控件变更时全量重建 `contentEl`；仅步骤跳转例外可全量刷新。

## 影响

- 交互顺畅、焦点与滚动稳定。
- 伴随 DOM 设计稳定后，样式与刷新逻辑更易收敛。
