# 决策：向导 UI 渲染策略（无刷新感 / 不跳顶）

## 背景

Step 3 中几乎任何控件变更（表单切换、模板下拉、添加规则、映射增删等）都触发 `render()` 全量重建 DOM——页面闪烁、滚动位置回到顶部、输入焦点丢失，体验差。

## 决策

| 级别 | 触发场景 | 刷新策略 |
| :--- | :--- | :--- |
| L1 仅预览 | 行清洗开关、行筛选/派生文本编辑 | `refreshPreviewOnly()` |
| L2 区块内 | 规则/映射/派生行增删改、类型变更 | 仅重建本区块容器 + 预览局部刷新 |
| L3 数据源级 | 表单/数据文件/模板切换 | 重解析后按依赖链刷新下游（映射 → 派生 → 预览），header/footer/body 不重建 |

实现原则：
- Step 3 的 body 滚动容器（`.ipw-body`）在整个 Step 内**保持 DOM 身份不变**；任何刷新前记录并恢复 `scrollTop`，杜绝「跳回顶部」。
- 各区块渲染函数**可重入**：首次构建持久容器，后续只重建内部内容。
- 输入控件状态即数据源（渲染只回填值），避免焦点丢失。
- **步骤切换例外**：Step 1/2/3/4 间跳转属页面结构切换，仍全量渲染（滚动置顶合理）。

## 影响

- Step 3 全部交互不闪烁、不回顶、焦点稳定。
- 规则 / 控件变更只触发局部渲染，性能与体验提升。
