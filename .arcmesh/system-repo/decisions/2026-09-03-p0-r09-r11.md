# 决策记录：Roadmap P0（R09/R10/R11）落地（2026-09-03）

## 背景

`components/roadmap.md` 将 R09（暂停/恢复/中断细节）、R10（导入前 Dry Run 确认统计）、R11（Dataview 自动索引刷新）列为 **P0（v1.0/M6）**。向导实现（D69–D75）已提供 Step 4 `[⏹ 停止]`（AbortSignal）与 Dry Run API 骨架，但：无暂停粒度、Step 4 直接写入无预检确认、无 after:import 内置 Dataview 刷新。本次补齐三项，并按既有约定同步蓝图与决策。

## 决策内容

| # | 决策 |
| :--- | :--- |
| D76 | **R09 协作式暂停（note 粒度断点）**：公共类型新增 `PauseToken`（architecture §7），`BatchConfig`/`ImportRecordsOptions` 增加 `pause` 与 `startAt`。运行时类 `PauseController`（`src/core/pause-controller.ts`）；`NoteGenerator.runWithConcurrency` 重构为选项对象，在取下一个 note 前检查 `pause.paused` 并以 `Promise.race([waitWhilePaused, abortPromise])` 等待恢复/中止——暂停不影响正在写入的 note（无半成品），`⏹ 停止` 可随时唤醒暂停 |
| D77 | **R09 断点续跑（停止后继续）**：`NoteGenerator.batchGenerate` 支持 `config.startAt`（跳过前 N 个已完成 note，同模板/同数据 → note 顺序确定，切片安全）；进度回调经 `base` 归位上报累计值；Step 4 运行页跨断点累计结果（`mergeRunResult`），停止后完成页提供「▶ 从断点继续」 |
| D78 | **R10 Dry Run 预检确认**：`importRecords({ dryRun: true })` 走 `NoteGenerator.dryRun`——dryRun 由"仅存在性判断"增强为"存在性 + 内容一致性"（现有笔记读旧内容比对，判 `skipped_unchanged` vs `updated`）；不写入、不记历史、不发 `import:complete`（发 `import:dryrun` 事件）。Step 4 先渲染预检页展示「将新建/更新/跳过/失败」+ 干跑结果，经「🚀 确认导入」才执行；「全部预检失败」时禁用确认 |
| D79 | **R11 Dataview 内置刷新**：`after:import` 登记入 `hooks/available-hooks.md` §9，并内置 Dataview 刷新行为——真实写入的导入完成（`importFile`/`importRecords` 均触发）且 `settings.refreshDataviewOnImport`（新设置项，默认 true）开启时调用 `refreshDataviewIndex(app)`（`src/core/dataview.ts`，兼容 `dataview.api.reindex` 与 `dataview.index.touch`）；未安装时记日志并对用户可见导入弹一次友好提示。设置页「🔄 导入行为」新增开关 |
| D80 | **向导关闭/中止安全**：`ImportModal.onClose` 中止仍在后台运行的导入（abort + 唤醒暂停），保留已写入笔记；`runImport` 在 await 后检测 `contentEl.isConnected`，向导关闭则不再渲染。随附缺陷修复：`applyRowCleaning` 的 `dedupe` 原按 `out.indexOf`（引用比较）去重实为失效，改为按内容 JSON 键去重（单测覆盖暴露该缺陷） |

## 边界与后续

- R09 停止前**不强制二次确认**（roadmap 原措辞"停止时询问是否保留已生成笔记"）：改为停止后明示「已保留已写入笔记」并提供「从断点继续」，降低打断成本；联调时按用户体验再定。
- R10 预检的 `skipped_conflict`（用户手动编辑保护）无法在 dryRun 精确预判（需 mtime/上次导入时间），近似为跳过口径；Dry Run 全失败时禁止确认写入。
- 外部文件端到端导入（R01）、多 Sheet 独立模板配置仍不在本次范围。
- 校验：`pnpm run type-check` 通过；本地单测直跑 `wizard-data`/`helpers` 全绿（37/37），门禁仍交 CI。待 Obsidian dev vault 联调（Step 3 布局/预览、Step 4 预检/暂停/断点）。
