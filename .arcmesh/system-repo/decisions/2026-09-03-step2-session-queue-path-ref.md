# 决策记录：Step 2 合并文件列表与路径引用（D66–D68）（2026-09-03）

## 背景

D65（`2026-09-03-file-picker-implementation.md`）落地后，Step 2 选择文件的现状为：原生文件选择器可用，但选完文件回到 Step 2 后仅于按钮右侧**回显文件名**，既不进入列表也不推进，无法点击"下一步"进入 Step 3，形成死端体验。

用户实测反馈期望行为：

1. 选好文件后，Step 2 的列表应**新增该文件条目并自动选中**；若列表中已存在该文件信息，则**直接选中、不新增**。
2. 之后可点击"下一步"进入 Step 3。
3. 所选文件**仅记录路径引用**：不预加载进内存、不写临时磁盘缓存，解析/预览时按需从原路径读取。
4. **合并列表**：原"待导入文件"与"历史记录"两个区块合并为**单一文件列表**；未导入的会话条目**自动删除**（不落历史），导入成功则**保留为历史条目**。

本决策在不破坏 D62–D64 平台抽象与 D65"外部文件不落库"边界的前提下，补齐 Step 2 会话状态与文件引用方式。

## 决策内容

| # | 决策 | 理由 |
| :--- | :--- | :--- |
| D66 | Step 2 文件列表**合并为单一列表**，条目分两类：**会话条目**（本次 `pickFile` 选择的文件，追加并自动选中；**去重键** = 文件来源标识（Vault 内 = 相对路径；外部 = 绝对路径；移动端 = 文件提供方标识），与列表已有条目——**含历史条目**——同标识 → **仅选中、不新增**；显示文件名 + 大小 + `[待导入]` 标签 + `[✕ 移除]`）与**历史条目**（来自 `importHistory`，显示模板名 + 导入条数 + 时间戳，支持"直接导入/修改模板/删除"）。**会话条目生命周期**：**未导入自动删除**——向导关闭（未成功导入）即移除该会话条目、不写入历史；**导入成功保留**——转为历史条目写入 `importHistory`（裁剪保留最近 20 条） | 单列表减少认知负担；去重横跨会话/历史条目避免同文件重复；会话条目不污染历史，导入成功才转正，历史语义清晰 |
| D67 | "**下一步**"门控 = 存在选中条目：有选中 → 可点进入 Step 3；无选中 → 禁用（历史条目"直接导入"不受影响）。保持"选择成功**不自动跳转**"（停留 Step 2 由用户确认）与"取消返回 `null` 不改向导状态"。D65"仅回显"升级为"列表条目 + 自动选中" | 由用户自主确认后推进；状态机可预测；外部文件"不落库"边界不变（见 D68） |
| D68 | **路径引用（Path Reference）**：`pickFile` 成功后**仅记录文件路径/标识**（桌面 = 本地绝对路径；Vault 内 = 相对路径；移动端 = 文件提供方标识/URI），**不预加载进内存、不复制、不写临时磁盘缓存**；Step 3 解析/预览**按需从原路径读取**（桌面直读文件系统；移动端经平台文件服务读取）。无驻留缓存 → 无清理生命周期：不需要 `onunload` 清理、不需要启动清扫孤儿文件。**约束**：解析/预览期间原文件需保持可访问；文件被移动/删除或移动端 URI 失效 → 错误码 `IO_002`，提示重选 | 零额外内存/磁盘开销、架构最简单；与"不落库"边界天然一致；按需读取即可满足 Step 3 解析与预览 |
| 边界 | 外部文件的**端到端导入**（Step 4 完成写入）仍随后续路线图（roadmap R01 类）提供；本决策仅放开"Step 2 队列 + Step 3 解析/预览读取" | 与 D65 里程碑边界一致，不扩大本次范围 |

## 修订记录

- v1.1.0（同日修订，实施前）：D68 由"内存优先 + 临时磁盘缓存（FileLoadManager）"改为"**仅记录路径引用**"——不预加载、不写临时缓存，随之取消清理生命周期（onunload 兜底/启动清扫均不再需要）；`ImportFileEntry` 去掉 `medium`/`tempPath` 字段，删除 `FileBufferOptions` 类型。
