# 决策记录：CI 修复 Ubuntu runner 缺少 zip（2026-09-03）

## 背景

测试修复推送后 CI 再次失败，本次失败步骤为 `Package`（`ci:package` = `ci:build && node scripts/package.mjs`；独立 `Build` 步骤已通过）。根因：`scripts/package.mjs` 在 Linux 分支执行 `cd dist && zip -r ../importer-pro.zip .`，而 GitHub `ubuntu-latest` runner 默认**未安装 `zip`**（`zip: not found`）。测试与构建均已通过，仅打包失败。

## 决策内容

| # | 决策 |
| :--- | :--- |
| D57 | 在 `ci.yml` 与 `release.yml` 的打包步骤前新增 `Install zip (Linux)` 步骤（`runner.os == 'Linux'` 时 `sudo apt-get update && sudo apt-get install -y zip`）。`scripts/package.mjs` 保持双平台分支不变（Windows 用 Compress-Archive），不引入 Node zip 依赖 |

## 影响

- `.github/workflows/ci.yml`：Package 前安装 zip。
- `.github/workflows/release.yml`：Build & Package 前安装 zip（该工作流同样在 ubuntu 上打包）。
- `.arcmesh/ops/CI_CD.md`：两处工作流文档同步。
- 蓝图版本升至 1.6.3（architecture/project）。
- 保留观察项：Node.js 20 运行时弃用 warning（不阻塞）。
