## 背景（用户需求，2026-09-06）

用户对 Step 3 区块 5（ui/layout.md §5.6，含 §5.6.2 笔记类型面板）提出七点 UI 修订：

1. 不需要把「添加设置」列的下拉放入「已添加设置」面板里面（下拉留在列内）；列更名「设置」；操作列的显示/隐藏已设置面板按钮（`⏵/⏷`）与徽标挪到此列，**徽标为 0 也不隐藏**。
2. 特殊字段下拉不要放在目标字段，直接放在**类型下拉框**（选项 = 中文名）；选中特殊字段后**将该行挪移到特殊字段面板**。
3. 特殊字段面板中的行应有：**来源（可修改）/ 类型（不可修改、中文名）/ 目标字段（不可修改、含说明）/ 设置（可弹出已设置面板和显示徽标）/ 操作（删除按钮）**这些列。
4. 特殊字段的添加设置下拉要**包含普通设置和特殊字段的设置**。
5. 特殊字段的列表**不需要排序按钮**。
6. 操作（行）和已添加设置的**拖拽排序应放在首列**。
7. 笔记类型面板中生成条件，下拉**不应该是选择来源，应该选择列映射中的目标列**；「文件名后缀」应该改成「文件名」。

约束衔接：D117（行下设置面板 + 分组下拉）已实现；D130（行顺序 = 内容模板顺序）/ D131（设置顺序 = 管道顺序）已实现；D132/D133（特殊字段行：目标字段下拉 + 联动 + 专属/默认设置）已实现；D120（笔记类型面板）已实现。本决策**修订** D117（列更名与显隐入口迁移）、D132（入口从目标字段下拉移至类型下拉）、D133（专属下拉合并进普通下拉）、D120（生成条件列来源与文件名标签）。

## 决策内容

### ① 设置列（原「添加设置」）

- 分组下拉**留在列内**，不放入「已添加设置」面板（面板只展示已添加设置项）。
- 列更名「添加设置」→ **「设置」**。
- 操作列的 `⏵/⏷` 显隐按钮与数量徽标移入本列；**徽标恒显（0 也不隐藏）**。
- 行下「已添加设置 (N)」面板仍列出 派生预设项 + 格式化/处理项 + 特殊字段专属设置项（特殊字段行另含**说明项**——中文名 + 用途），每项可 `✎` 编辑、`✕` 删除、`↑/↓` + 拖拽重排（D131 管道顺序语义不变）。

### ② 特殊字段入口（修订 D132）

- 特殊字段下拉**从目标字段移除**，放入**「类型」下拉**的「特殊字段」分组（选项 = **中文名**：`_skip`=跳过记录、`_folder`=目标文件夹、`_fileName`=文件名、`_status`=状态、`_warnings`=警告列表、`_link`=智能链接；每个**唯一**、已配置者灰置「已配置」）。
- 在「类型」下拉选中特殊字段后，该行**从普通映射表挪移到区块 5「特殊字段面板」**（普通行 ⇄ 特殊字段行互移；真实特殊字段行不参与普通行排序段，D130 段内顺序口径不变）。

### ③ 特殊字段面板（修订 D132/D133 显示形态）

- 面板行列 = **来源（可修改）/ 类型（不可修改、中文名）/ 目标字段（不可修改、含说明）/ 设置（`⏵/⏷` 弹出已设置面板 + 徽标）/ 操作（删除按钮）**。
- `_skip`/`_folder`/`_fileName` 仍为区块 4/3 **联动视图行**（面板显示摘要、✕ 清除对应上方区块配置并复位）；`_status`/`_warnings`/`_link` 仍为**真实行**（入 cfg.mappings、`ipro:specialrow` 标记反编译）。
- 特殊字段的**说明（中文名 + 用途）**随默认设置放入「已添加设置」面板（说明项）。

### ④ 特殊字段设置下拉（修订 D133）

- 特殊字段行的「设置」下拉**合并普通设置（七组）+ 特殊字段的设置**（条件/输出表达式/固定值/条件警告/smartLink），不再独立专属下拉。

### ⑤⑥ 排序与拖拽

- 特殊字段的列表**不需要 `↑/↓` 排序按钮**（拖拽仍可用）。
- 行拖拽把手 `⋮⋮` 从操作列移至**表格首列**；已添加设置的拖拽把手放**设置项首列**。

### ⑦ 笔记类型面板（§5.6.2，修订 D120）

- 生成条件列下拉改为选择**列映射中的目标列（目标字段）**，不是来源列。
- 「文件名后缀」标签更名 **「文件名」**。
