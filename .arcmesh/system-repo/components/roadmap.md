# 能力差距与路线图（Roadmap）

## 1. 目的

对标官方 Importer、obsidian-data-importer、JSON-CSV Importer、obsidian-process 等同类工具，登记 Importer Pro 的能力差距项，并给出优先级与目标版本。本组件是差距项的唯一登记处，实现前须先在此更新状态。

## 2. 优先级定义

| 优先级 | 含义 | 目标版本 |
| :--- | :--- | :--- |
| **P0** | 发布必备，基于既有蓝图能力补细节/UI | v1.0.0（2026-11-01） |
| **P1** | 高价值进阶能力，需新增模块设计 | v1.1（待定档期） |
| **P2** | 远期/按需，暂不做详细设计 | 待决策 |

| R01 | Markdown 文件夹 / ZIP 批量导入 | 官方 Importer | P1 | v1.1 | 待开始 | 保留源目录层级、相对链接、附件、`.base`、`.canvas`；保留层级可配置 |

## 4. 实施说明

- **P0 三项**（R09/R10/R11）均基于既有蓝图能力补细节：`dryRun` API（api-layer §3.3）、进度面板（layout §6）、钩子 `after:import`（hooks/available-hooks.md）。
- **P1 项**涉及新模块或接口扩展，开工前须在本组件补充对应设计并更新决策记录：
  - R01/R02：`DataParser` 新增 Markdown 文件夹/ZIP 解析（层级、附件、`.base`/`.canvas` 保留）
  - R06：`JSONParser` 嵌套路径语法 + `DataPipeline` 上下文注入
  - R07/R08：新增导入任务管理器（后台队列、进度通知、断点持久化于 `data.json`）
  - R03/R04/R05：`TemplateScanner` 模板库 + 配置向导的类型推断/关系建议
- **P2 项**暂不设计，仅在排期评审时重新评估。
