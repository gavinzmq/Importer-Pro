# UI（向导 + 设置页）

> **TL;DR**：4 步图形化向导 + 设置页四分区。

## 一、4 步向导总览

| Step | 名称 | 内容 |
| :--- | :--- | :--- |
| 1 | 来源选择 | 纵向列表按分组（笔记应用 / 文件格式）选数据源 |
| 2 | 文件管理 | 单一文件列表：会话条目（本次选择）+ 历史条目（模板名 + 导入条数 + 时间戳，可快速导入） |
| 3 | 模板配置 | 6 区块核心配置（模板级→行级→列级→结果），见下 |
| 4 | 进度执行 | Dry Run 预检 → 实时进度/滚动日志；暂停/恢复/停止/断点续跑 |

Modal 布局：Header Bar（返回/Step 指示/✕）+ Body（滚动）+ Footer Bar（取消/上一步/下一步）。桌面宽 720px / 移动全屏；`styles.css` `.ipw-*` 样式。

## 二、Step 1：来源选择
格式分组：📱 笔记应用（Apple Notes `.notes` / Evernote `.enex` / Notion `.zip`）；📂 文件格式（Excel `.xlsx/.xls` / CSV/TSV `/ JSON / HTML`）。列表项 = 图标 + 主名称 + 描述 + 格式标签 + 悬停右箭头。

## 三、Step 2：文件管理
- **[📁 选择文件]** 经 `IFilePicker` 接口 + `FilePickerFactory` 反射工厂调用平台原生能力（桌面 OS 对话框 / 移动系统文档选择器）；`accept` 按 Step 1 来源映射过滤格式。
- 会话条目：选中文件仅记录**路径引用**（外部文件携 `File/Blob` 句柄 D81），未导入自动删除；导入成功转历史条目（保留最近 20 条）。
- 历史条目操作：🔄 直接导入 / 📝 修改模板 / 🗑 删除。下一步门控：有选中条目才可用。

## 四、Step 3：模板配置（6 区块）

| 区块 | 归类 | 内容 |
| :--- | :--- | :--- |
| 1 文件信息条 | — | 文件 + 检测工作表数（灰底） |
| 2 数据表单选择 | — | 多 Sheet 选择 / 同时导入所有表单（Excel 时显示） |
| 3 模板元信息 | 模板级 | 模板名称、匹配规则与优先级、冲突策略/增量模式、**输出位置及命名规则**；操作行 [📝 编辑模板代码] [➕ 新建模板] [💾 保存到模板] [💾 保存到内容模板] |
| 4 行配置 | 行级 | 行清洗（过滤空行·过滤重复表头 → Handlebars 段）；行筛选（Excel 式包含筛选，多组 OR）；表头 = 清洗+筛选后剩余第一行 |
| 5 列映射与派生 | 列级 | 列映射合并单表：来源 → 目标字段 → 类型 → 输出到 → 设置 → 操作；按钮行与 💡 可用源列置顶；⭐ 特殊字段面板（恒显 + 顶部「添加特殊字段」下拉）；📑 笔记类型面板（多笔记，D120） |
| 6 预览区 | 结果 | 真实渲染（`renderPreprocess` 前 N 行）+ 多笔记展开 |

- 全部配置保存 = 编译为模板 preprocess 标记段（`ipro:begin/end`）写回（**模板即配置源**，见 `decisions/data-flow-preprocess-storage.md`）。
- 行顺序 = 内容模板字段顺序；设置顺序 = 值管线顺序。
- 渲染策略（无刷新感/不跳顶，D91）见 `decisions/ui-render-strategy.md`；逻辑分离见 `decisions/ui-logic-separation.md`。

## 五、Step 4：进度执行 + 完成页
- **Dry Run 预检**（R10）：进入默认呈现「将新建/更新/跳过/失败」统计，确认后写入。
- 执行页：进度条 + 成功/失败/跳过统计 + [⏸ 暂停] [▶ 继续] [⏹ 停止]；滚动日志区（虚拟滚动，最多 50 条）。
- 暂停在 note 粒度断点生效（无半成品）；停止保留已写入笔记，完成页提供「▶ 从断点继续」。
- 完成页：统计卡片（总记录/成功/失败/跳过 + 耗时）+ 错误详情 + [📥 导出错误报告] [📂 打开文件夹] [✅ 完成]。

## 六、设置页（SettingsTab）
四分区 + 高级操作：
| 分区 | 设置 | 默认 |
| :--- | :--- | :--- |
| 📂 路径设置 | 模板/输出/数据根/Helper/Hook/缓存/日志目录 | `_templates/`、空(Vault 根)、`Data/`、`_helpers/`、`_hooks/`、`.obsidian/importer-pro/`、`.../logs` |
| 🔄 导入行为 | 冲突策略、增量模式、数据分流、智能链接、并发写入、自动匹配、CSV 编码、刷新 Dataview、历史条数 | overwrite / hash / 开 / 开 / 5 / 开 / auto / 开 / 20 |
| 💾 缓存设置 | 提供者、刷新间隔、启动预热 | auto / 300s / 开 |
| 📋 日志设置 | 级别、控制台、文件、保留天数 | info / 开 / 开 / 7 |
| 🔧 高级 | 重置默认 / 导出/导入配置（JSON，校验 schemaVersion） | — |

路径仅允许 Vault 内相对路径（越界 → `SECURITY_001`）；保存即写 `data.json` 并按 `schemaVersion` 迁移。权威字段 ↔ `references/plugin-settings.md`（L4）。
