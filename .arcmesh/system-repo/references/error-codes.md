## 快速查找（按前缀）
- `TEMPLATE_`：模板（001/004/005）
- `PARSE_`：解析（001/002）
- `CACHE_`：缓存（001）
- `IO_`：文件读写（001/002）
- `GENERATE_`：生成（001）
- `MERGE_`：合并（001）
- `API_`：API参数（001）
- `SECURITY_`：安全（001）

---

## TEMPLATE_ 模板错误
| 错误码 | 消息 | 说明 |
| :--- | :--- | :--- |
| TEMPLATE_001 | 模板未找到 | 匹配规则未命中任何模板 |
| TEMPLATE_004 | 模板解析失败 | Frontmatter或preprocess段格式错误 |
| TEMPLATE_005 | 模板写入失败 | 保存配置时文件写入错误 |

## PARSE_ 解析错误
| 错误码 | 消息 | 说明 |
| :--- | :--- | :--- |
| PARSE_001 | 不支持的文件格式 | 文件扩展名不在支持列表中 |
| PARSE_002 | 解析失败 | 文件损坏/指定sheet不存在/编码错误 |

## CACHE_ 缓存错误
| 错误码 | 消息 | 说明 |
| :--- | :--- | :--- |
| CACHE_001 | 缓存未就绪 | 缓存提供者未初始化 |

## IO_ 文件读写错误
| 错误码 | 消息 | 说明 |
| :--- | :--- | :--- |
| IO_001 | 写入失败 | 目标路径不可写或权限不足 |
| IO_002 | 文件读取失败 | 原文件不可访问或提供方URI失效 |
